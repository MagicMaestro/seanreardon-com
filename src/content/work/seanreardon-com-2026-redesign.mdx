The site you're reading. A 2015 PHP/MariaDB portfolio I'd been adding to for years finally outgrew its design — both technically (PHP 5.6, MariaDB schema I'd grown past, no responsive layout) and editorially. The 2026 redesign isn't a refresh. It's the project I'm running right out in the open as I build and experiment with AI integration in a working web stack.

**The current stack:**

- Astro 5 with React islands for the interactive components
- Self-hosted on a VPS I admin myself (no Vercel / Netlify lock-in)
- Listmonk for the newsletter
- Cloudflare for CDN and cookieless analytics

The header you see — gear, brushed-nickel bar, running laser channels — is deliberate vocabulary: every interactive surface on the site uses the same "energy" treatment because the site is energetic with what's happening inside it.

The redesign's content model is ship-and-explain. Every significant decision becomes a retrospective post; the technical work and the writing about it are the same surface. What's not yet here: the first v1 AI feature I'll be shipping. It's in the works and I'll be dropping a retrospective on the process once it ships. Until then, the most recent posts take the lead.
